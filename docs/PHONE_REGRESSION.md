# Mercate — phone regression checklist

Install the latest **mercate-apk** from Actions, then run through this on a real device.

## Setup

1. Open app → set **Shop name** (Home → storefront / profile).
2. Choose profile **Mama mboga / fresh produce** (PIN if lock is on).
3. Settings → Appearance: try **Light** and **Dark**.
4. Optional: Settings → Set PIN → Require unlock.

## Mama mboga stock

1. **Stock** → + add product:
   - Name e.g. *Sukuma*
   - Unit chips: **kg / bunch / heap / piece** (default kg)
   - Selling price, cost, opening stock, minimum stock
2. Add 2–3 more items (tomatoes heap, onions kg, eggs dozen).
3. Confirm glass cards show stock and **LOW/OUT** when relevant.

## POS sell

1. **POS** → tap products into cart (glass cart panel).
2. Adjust qty with +/-.
3. **Pay** cash → complete → snackbar + History receipt.
4. Quick sale (flash) for something not in stock → Pay M-Pesa **with reference**.
5. Credit sale: pick customer, leave balance → Pay.
6. Split: SPLIT → cash + M-Pesa legs → Pay.

## Customers / debt

1. **Customers** → + add person with phone.
2. Wallet → Debtors → confirm balance.
3. Statement → **Repay** partial cash.
4. Home notifications (bell) after low stock / debt scan.

## Day ops

1. Home → **Expense** (e.g. transport).
2. Confirm glass metrics: sales, cash, M-Pesa, expenses.
3. **Close day** (PIN if enabled) → count cash/M-Pesa.

## Void

1. History → open receipt → **Void** with reason (PIN if enabled).
2. Confirm stock restored and debt reversed if credit sale.

## Reports

1. **Reports** → glass totals look right for today.
2. Share PDF → open in Files / WhatsApp.

## Assistant

1. FAB or POS app-bar sparkle → ask *Explain business profiles* and *What did I sell today?*.

## Pass criteria

- No crash on any step above.
- Mama mboga: **no Suppliers tab**.
- Glass visible on Home, POS, Stock, Customers, Reports.
- Logo on Home header / lock screen when asset present.
